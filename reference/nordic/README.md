# Nordic sources

These sources describe different layers. Do not combine them into one universal
"Ediel format".

| Collection | What it helps explain |
| --- | --- |
| [`ediel-guides.json`](../catalogs/ediel-guides.json) | Nordic EDIFACT implementation guides |
| [`nmeg-common.json`](../catalogs/nmeg-common.json) | XML conventions, business requirements and Nordic code lists |
| [`nmeg-nbs.json`](../catalogs/nmeg-nbs.json) | Nordic balance-settlement processes and schema packages |
| [`esett-communications.json`](../catalogs/esett-communications.json) | eSett communication guides, examples and service interfaces; links only |
| [`esett-handbook.json`](../catalogs/esett-handbook.json) | Settlement handbook editions/translations; links only |
| [`entsoe.json`](../catalogs/entsoe.json) | European CIM/ESMP schemas, code lists and implementation guides; links only |

Nordic business requirements, European schema definitions, national rules and a
specific counterparty's supported release must agree. A draft on an official
website is still a draft. Bundle contents and third-party rights need review
before downloading or promoting a schema package into application dependencies.
