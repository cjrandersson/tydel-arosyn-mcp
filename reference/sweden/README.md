# Swedish sources

Use the national implementation rules before choosing a message profile.

| Collection | Start here |
| --- | --- |
| General Ediel, UTILTS, PRODAT, APERAK, DELFOR, AI/SI lists and code lists | [`ediel-se.json`](../catalogs/ediel-se.json) |
| Market processes and responsibilities | [`swedish-handbook.json`](../catalogs/swedish-handbook.json) |
| Measurement and reporting regulation | [`regulation.json`](../catalogs/regulation.json) |

The [Ediel portal](https://www.ediel.se/Info/EdielAnvisningar) lists historical
instructions separately. Those entries retain `archive` status in the catalogue.
Natural-gas instructions are not the default rules for electricity messages.

The AI list is an Ediel business-data list; "AI" here does not mean artificial
intelligence. XLS/XLSX and HTML instructions are reference files, not code to run.
